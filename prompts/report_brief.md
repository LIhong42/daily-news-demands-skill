# 写报告指令（Claude 阅读并按此执行）

> **触发条件**：用户在 daily-news skill 中要求"生成报告/写日报/整理今日热点"。
> **本指令定义了 Claude 在产完需求后，应如何撰写 Markdown 报告、如何落库。**

---

## 你的任务

根据当日新闻（已入库）和需求（你刚挖掘并入库的），撰写两份 Markdown 报告：
1. **新闻报告**：今日热点精选
2. **需求报告**：可执行的产品需求汇总

---

## 新闻报告结构

```markdown
# 每日热点简报 · YYYY-MM-DD

## TL;DR
3-5 句要点：
- 今日最热的 1-2 个话题
- 跨源出现的趋势信号（≥3 个来源讨论 = 趋势）
- 今日最重要的 1 条需求

## 一、今日热点 TOP 10（按重要性排序）
对每条新闻：
- **标题**（来源 · 时间）
- 一句话总结
- 为什么重要 / 趋势信号
- 关联需求（如有）

## 二、跨源趋势
指出今日哪些话题在 ≥3 个来源出现：
- 话题 A：来自 X、Y、Z → 说明它是真趋势
- 话题 B：来自 M、N → 待观察

## 三、明日观察
3 个值得继续追踪的议题。

---
字数 ≤ 1500。中文。短句为主。
```

---

## 需求报告结构

```markdown
# 今日需求清单 · YYYY-MM-DD

> 共 N 条需求 · 最高优先级 X.X · 高可行性 M 条

## 一、TOP 5 高优先级需求
对每条：
- **需求标题**
- 目标用户（一句话）
- 痛点（量化）
- MVP 方案（≤80 字）
- 可行性：xxx / 优先级：x.x
- 关联新闻：[标题1] [标题2]

## 二、按可行性看板
- 🟢 高可行性：X 条（列标题 + 一句话）
- 🟡 中可行性：Y 条
- 🔴 低可行性：Z 条

## 三、跨日对比（可选）
对比昨日需求，哪些上升/下降/新增/消失。

## 四、行动建议
- 本周可以动手的 1-2 个
- 值得继续挖掘的方向

---
字数 ≤ 1200。中文。
```

---

## 写作风格

- **中文**
- **短句、列表为主**，避免长段落
- **不要堆砌空话**（"显著优化""大幅提升"等）
- **量化优于形容词**（"降低 30% 退货成本"）
- 链接：`[标题1](https://...)`

## 保存方式

### 新闻报告

```bash
python scripts/cli.py save-news-report --markdown - --date today << 'EOF'
# 每日热点简报 · ...
...
EOF
```

### 需求报告

```bash
python scripts/cli.py save-demand-report --markdown - --date today << 'EOF'
# 今日需求清单 · ...
...
EOF
```

成功标志：CLI 输出 `✓ ... 报告已保存 (uuid=...)`

## 完成后的下一步

1. 用 Bash 执行：`python scripts/cli.py report --format html --date today`
2. 用 Read 工具打开 `reports/<today>/report.html`，向用户总结：
   - 今日抓到了多少条新闻、哪些来源
   - 挖出了多少条需求、最高优先级多少、高可行性几条
   - 1-2 条最值得动手的需求（带标题和 MVP 方案）
3. 把 `reports/<today>/report.html` 的绝对路径告诉用户，方便他们打开浏览器
